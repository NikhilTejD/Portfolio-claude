# Portfolio site (GitHub Pages)

- `index.html` - homepage
- `cases/` - one page per case study (`case-template.html` is the blank to copy)
- `files/` - Excel, PDF and other downloads linked from case pages
- `_build/` - source pieces; run `python3 _build/build.py` to regenerate case pages

Publish: repository Settings -> Pages -> deploy from the main branch, root folder.
